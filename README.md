# Andres Orozco | Professional Portfolio

Welcome to my personal professional portfolio website, built using **Vue 3 and Vite**.

## About This Project

This portfolio showcases my development as an aspiring software developer and IT professional. It will continue to grow throughout the semester as I gain experience with Vue, web development, and other technologies.

The website features a responsive layout with a modern dark theme and purple accents.

## Website Design Documentation

The initial design planning for this website includes:

- **Conceptual Site Map:** Home, About, Projects, Skills, Resume, and Contact.
- **Page Layout:** Navigation header, professional introduction, profile photo, and footer.
- **Color Palette:** Midnight Purple theme with dark backgrounds, violet accents, and light text.
